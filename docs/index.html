How to read the plots

Left: summed impact ÷ available cycles. Middle: summed accepted observation count ÷ available cycles. Right: summed impact ÷ summed accepted observation count (equivalently, mean impact per cycle ÷ mean count per cycle). Zero observation count is shown as N/A.
Impact is (OMA² − OMB²) / observation-error², with no ½ factor. Negative values indicate reduced normalized observation departures. Wind counts are scalar U/V components; satellite counts are location/channel elements. All bars use the same color.
Missing hourly files are excluded from the cycle denominator. Types absent from an available file contribute zero to its average; the numerical table shows type coverage. The input workflow converts missing-type NaN impacts to zero, so zero values alone do not establish observation availability.
